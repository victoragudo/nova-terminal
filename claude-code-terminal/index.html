What makes a good terminal for Claude Code?

A good terminal for Claude Code keeps up with fast streaming output, handles multi-line prompts and makes several agents easy to follow. Most terminals cover the first two. The third is where your day goes: tabs pile up, and you keep checking each one to see whether an agent is done or stuck on a question.

  • Smooth output. Nova draws on the GPU through Metal, and each frame copies the screen and lets go of the lock at once, so long diffs never stall the UI.
  • Shift+Enter just works. New lines in a prompt need no /terminal-setup and no custom key bindings.
  • One view for every agent. The Agents view tells you which session needs you, which is working and which is idle.

See every agent at once

Press ⌘ ⇧ A. Nova finds every Claude Code and OpenCode session running on your Mac, including subagents and Claude Code profiles, with nothing to set up. Sessions are grouped into Needs you, Working and Idle.

Click one to see its project, branch, how long it has been running, how much context it uses and its last steps: edits, commands, reads, searches and messages. Go to tab jumps to its terminal.

Approve permission prompts without switching tabs

When an agent stops to ask for permission, the question shows up in the Agents view. Approve it or interrupt the agent from there, and move on to the next one.

Find and resume any Claude Code session

⌘ ⇧ O lists every Claude Code session you have ever run, across all your profiles, with full-text search over the conversations. Open one and Nova resumes it in a new tab, in the folder it started from. ⌘ Y shows the whole conversation, and you can rename sessions or move old ones to the Trash.

Know when a background agent finishes

When a tab in the background finishes its work, Nova sends a native macOS notification. Click it and you land on that tab.

Check on your agents from your phone

Nova Remote opens your live tabs in any browser. Watch an agent stream its output, answer a question with big keys for Enter, Ctrl-C, Esc and the arrows, or browse your Claude sessions and resume one on the Mac.

See what you sent the agent

Hover an [Image #1] or [Pasted text #2] placeholder in the terminal to preview what the agent received. ⌘-click opens the file.

Artifacts beside the terminal

When Claude Code publishes a claude.ai Artifact from the current tab, Nova can open it in a side panel next to the terminal. ⌘ ⇧ E lists every Artifact your sessions have published.

How to set up Nova for Claude Code

  1. Download the latest DMG and drag Nova to Applications.
  2. Open Nova and run claude. Your login shell loads your usual PATH, so the Claude Code you already installed works as is.
  3. Start more agents in other tabs, or split with ⌘ D.
  4. Press ⌘ ⇧ A to see which session needs you.

Frequently asked questions

What is the best terminal for Claude Code on Mac?

The best terminal for Claude Code renders streaming output smoothly, supports Shift+Enter for new lines and makes several sessions easy to manage. Nova does all three and adds an Agents view that lists every Claude Code session, shows which one needs you and lets you approve prompts in place.

Does Shift+Enter work for new lines in Claude Code?

Yes. Nova sends a newline on Shift+Enter out of the box, so you can write multi-line prompts in Claude Code without running /terminal-setup or changing key bindings.

Does Nova work with OpenCode too?

Yes. The Agents view finds both Claude Code and OpenCode sessions running on your Mac, and attachment previews understand the image and PDF placeholders of both tools.

Can I use several Claude Code accounts?

Yes. Nova reads every Claude Code config folder, the default ~/.claude and each profile under ~/.claude-profiles, so the Agents view and the session finder cover all your accounts. Resuming a session reopens it with the right config folder.

Is Nova made by Anthropic?

No. Nova is an independent macOS terminal by Víctor Agudo. It works with Claude Code by reading the session files Claude Code keeps on your Mac, with nothing to configure.
