What is Nova Terminal?

Nova Terminal is a free, native terminal for macOS written in pure Rust. It renders through Metal with GPUI, the UI framework behind the Zed editor, on top of the alacritty_terminal core. Next to the shell it keeps a file tree that follows cd, instant previews, a Git panel, split panes and an Agents view for Claude Code and OpenCode.

Nova vs Warp at a glance

Both are modern, GPU-rendered terminals written in Rust. The difference is in what they put around the shell and how they handle AI.

Why do developers look for a Warp alternative?

The reasons people give usually fall into a few groups:

  • They already pay for an AI agent. If Claude Code or OpenCode does your coding, a second AI plan inside the terminal is money spent twice.
  • They don't want an account in their terminal. A terminal sees everything you type, so many developers prefer one with no sign-in and no cloud layer.
  • They run several agents at once. Juggling five Claude Code tabs is hard when you can't tell which one is waiting for you.
  • They want the classic shell flow. Nova keeps a plain, full-screen terminal grid, so tmux, vim, htop and every TUI behave exactly as they do in Terminal.app.

What you get with Nova

An Agents view for every coding agent on your Mac

Press ⌘ ⇧ A and Nova lists every Claude Code and OpenCode session running on the machine, subagents and profiles included. Sessions are grouped into Needs you, Working and Idle. When an agent waits on a permission prompt, the question shows up in the panel and you can approve it or interrupt the agent right there. More on this in the terminal for Claude Code.

Files, previews and Git next to the shell

The sidebar re-roots whenever you cd. Create, rename, move and delete files, preview code with syntax colors, images, SVG, PDF and zip listings, and commit, pull or push from a small Git panel.

Split panes you can drag around

Split right with ⌘ D or down with ⌘ ⇧ D, drag a tab onto the terminal to join it, name each pane and even out the sizes with ⌘ ⌥ =. Layouts come back when you relaunch.

Your tabs on your phone

Nova Remote opens your real windows in any browser, through a Cloudflare tunnel or your LAN. Watch an agent work from the couch and type back, with big keys for Enter, Ctrl-C, Esc and the arrows.

Fast, and quiet on the battery

Each frame copies the visible screen and releases the lock straight away, so painting never waits on the shell. Slow work stays off the main thread, and every animation stops when the window is in the background.

When is Warp the better choice?

Pick Warp if you need the same terminal on Linux or Windows, if you want an AI agent built into the terminal itself, or if your team shares commands and notebooks through Warp Drive. Nova is macOS only and leaves AI to the agent of your choice.

How to switch from Warp to Nova

  1. Download the latest DMG and drag Nova to Applications.
  2. Open Nova. Your shell starts as a login shell, so your zsh or bash profile, aliases and prompt load as usual.
  3. Press ⌘ K to find any command, tab, theme or Claude session by name.
  4. Run claude or opencode in a few tabs, then press ⌘ ⇧ A to see all of them at once.

Other Warp alternatives for macOS

Nova is not the only option. Depending on what you value:

  • Ghostty: a fast, native terminal with sensible defaults and a focus on standards.
  • iTerm2: the long-standing macOS terminal, with deep configuration and tmux integration.
  • WezTerm and Kitty: GPU-accelerated, cross-platform terminals configured through code.

Choose Nova if you spend your day with Claude Code or OpenCode and want files, previews, Git and an overview of every agent in the same native window.

Frequently asked questions

Is Nova a free alternative to Warp?

Yes. Nova is a free macOS terminal with no paid plans and no AI credits. It is a native Rust app drawn on the GPU through Metal, like Warp, but it leaves AI to the coding agents you already use, such as Claude Code and OpenCode.

Does Nova need an account or a login?

No. Nova has no account, no sign-in and no analytics. You download the DMG, drag the app to Applications and open it. Updates arrive through Sparkle.

Does Nova have AI built in like Warp?

Nova does not ship its own model or agent. It is built around the agents you already run: an Agents view lists every Claude Code and OpenCode session on your Mac, groups them by Needs you, Working and Idle, and lets you approve or interrupt a permission prompt in place.

Will my Warp shell setup work in Nova?

Your shell setup carries over. Nova starts each tab as a login shell, so zsh or bash loads the same profile, aliases, prompt and PATH as Terminal.app. Warp-specific features such as Warp Drive workflows do not carry over.

Does Nova run on Linux or Windows?

No. Nova is macOS only and needs an Apple Silicon Mac with macOS 13 or newer. If you need the same terminal on Linux or Windows, Warp or a cross-platform terminal such as WezTerm is a better fit.
