# Contributing to Nova Terminal

Thanks for helping make Nova better. This repo hosts the releases, the update feed, the docs and the issue tracker. The app source lives in a private repo, so most contributions start as an issue.

## Report a bug

Open a [bug report](https://github.com/victoragudo/nova-terminal/issues/new?template=bug_report.yml). Include your Nova version (Nova > About Nova), your macOS version and the exact steps. A screenshot or a short screen recording helps a lot.

## Suggest a feature

Open a [feature request](https://github.com/victoragudo/nova-terminal/issues/new?template=feature_request.yml). Describe the problem you want solved before the solution you have in mind; it makes it easier to find the right fix.

## Send a pull request

Pull requests are welcome for the README and the docs: typos, clearer wording, better screenshots, missing details.

1. Fork the repo and make your change on a branch.
2. Open a pull request against `main` and fill in the template.
3. I review every pull request. It is merged once I approve it, with a squash merge.

Please do not edit `appcast.xml`. It is generated by the release pipeline and changes to it are rejected.

## Security issues

Do not open a public issue for a security problem. Use [private vulnerability reporting](https://github.com/victoragudo/nova-terminal/security/advisories/new) instead.

## Code of conduct

Be kind and assume good intent. Harassment or personal attacks get the issue or pull request closed.
